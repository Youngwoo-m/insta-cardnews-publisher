# 인스타 카드뉴스 수동 발행기

내가 만든 카드 이미지를 웹 화면에서 올리면 **인스타그램 캐러셀**로 발행해 주는
로컬 웹앱입니다. 뉴스 수집·카드 생성이 자동으로 도는 `insta-cardnews` 와는
**별개 프로젝트**이고, 스케줄과도 무관합니다(내가 누를 때만 동작).

```
브라우저에서 카드 6장 업로드 → 순서 조정 → 캡션 작성(AI 초안 가능)
   → 미리보기 → 테스트 → 발행
```

## 실행

```bash
./run.sh
```

띄운 뒤 브라우저에서 http://127.0.0.1:5252 로 접속합니다.
`127.0.0.1` 에 고정돼 있어 **이 맥에서만** 열립니다(같은 와이파이의 다른 기기도 접근 불가).

## 화면 사용법

1. **카드 이미지** — 드래그&드롭 또는 클릭해서 선택(최대 10장, PNG/JPG).
   올린 뒤 썸네일을 **드래그해서 순서를 바꿀 수 있습니다**. `×` 로 뺍니다.
   비율이 서로 다르거나 첫 장이 1:1 이 아니면 경고가 뜹니다
   (캐러셀은 첫 장 비율에 맞춰 나머지가 잘립니다).
2. **캡션** — 직접 쓰거나 `✨ AI 초안` 을 누릅니다. AI 는 **업로드한 카드 이미지를 직접 읽고**
   그 안에 있는 사실만으로 캡션을 씁니다. 옆 메모칸에 방향을 적으면 반영합니다.
   초안일 뿐이니 그대로 고쳐 쓰면 됩니다.
3. **해시태그** — 지역 태그(제천·충북·세명대 등)가 기본으로 채워집니다(채널 브랜딩 규칙).
   `첫 댓글로 분리` 를 켜면 본문은 깔끔해지고 해시태그가 첫 댓글로 갑니다.
4. **미리보기** — 실제 게시에 쓰이는 것과 **같은 조립 로직**으로 최종 문구를 보여줍니다.
5. **발행**
   - `로그인 확인` — 게시하지 않고 세션만 점검합니다.
   - `테스트` — 캡션 입력까지 전부 하고 **'공유하기' 직전에 멈춥니다.** 게시되지 않습니다.
     결과는 `logs/` 의 `caption_screen`·`before_share` 스크린샷으로 확인하세요.
   - `인스타에 발행하기` — 확인창을 한 번 거친 뒤 실제로 게시합니다.

발행 중에는 Chrome 창이 자동으로 열립니다. **창을 닫지 마세요.**
보안확인(CAPTCHA)이 뜨면 그 창에서 직접 풀어 주시면 이어서 진행됩니다.

## 구조

| 파일 | 역할 |
|---|---|
| `app.py` | Flask 서버(업로드·캡션·미리보기·발행 API). 한 번에 한 건만 실행 |
| `templates/index.html` | 화면 전부(드래그 정렬·미리보기·실시간 로그) |
| `caption_ai.py` | 카드 이미지를 Claude 에게 보여주고 캡션 초안 받기 |
| `ig_bridge.py` | **insta-cardnews 의 게시 로직을 빌려 쓰는 다리** |
| `core.py` | 설정·경로·로그 |
| `login_setup.py` | 세션 만료 시 재로그인용 |

### ig_bridge 가 하는 일

인스타 웹 DOM 은 자주 바뀌고 그 대응 로직이 `insta-cardnews/post_instagram.py` 에
이미 쌓여 있습니다. 복사해 오면 인스타가 바뀔 때마다 **두 군데를 고쳐야** 하므로,
그 모듈을 그대로 import 한 뒤 **프로필·로그·설정만 이 프로젝트 것으로 갈아끼웁니다.**
→ `insta-cardnews` 쪽을 고치면 이 앱도 같이 고쳐집니다.

`insta-cardnews` 를 옮겼다면 `config.json` 의 `cardnews_dir` 에 경로를 적어주세요.

예외가 하나 있습니다. 원본의 첫 댓글 함수는 **릴 전용**(`/reels/`)이라 캐러셀에는
못 씁니다. 그래서 `_comment_on_latest_post` 만 이 프로젝트에서 따로 구현했습니다
(헬퍼는 원본 것을 재사용).

## 로그인

Chrome 프로필(`chrome-profile/`)은 `insta-cardnews/chrome-profile-insta` 를 **복사해서**
시작했으므로 이미 `@smu_ds_official` 로 로그인돼 있습니다. 프로필이 분리돼 있어
수·토 08:30 스케줄이 도는 중에도 충돌하지 않습니다.

세션이 만료되면:

```bash
./.venv/bin/python login_setup.py
```

창이 열리면 직접 로그인한 뒤 터미널에서 Enter. (자격증명·CAPTCHA 는 사람이 직접)

## 설정 (`config.json`)

| 키 | 설명 |
|---|---|
| `anthropic_api_key` | AI 초안용. `insta-cardnews` 것과 동일 |
| `caption_model` | 기본 `claude-opus-5` |
| `cardnews_dir` | insta-cardnews 경로. 비우면 `../insta-cardnews` |
| `instagram.username` | 첫 댓글을 달 때 프로필을 찾는 데 씀 |
| `instagram.follow_cta` | 캡션 끝에 붙는 팔로우 유도 문구 |
| `hashtags` / `local_tags` | 해시태그 기본값. `local_tags` 는 항상 포함 |

## 주의

- 인스타 웹 자동화는 메타 ToS 상 권장 방식이 아닙니다. 저빈도·실제 로그인 프로필로
  위험을 낮췄지만 계정 제재 가능성이 0은 아닙니다.
- 더 안정적으로 운영하려면 **Instagram Graph API**(공식) 전환이 답입니다. 다만
  프로페셔널 계정 + 페이스북 페이지 연결 + Meta 앱 + 이미지의 공개 HTTPS URL 이 필요합니다.
- 비용: AI 초안 1회에 Claude 토큰 몇 센트. 안 쓰면 0원.
