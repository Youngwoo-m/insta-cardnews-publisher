# 인스타 카드뉴스 발행기

직접 만든 카드 이미지를 웹 화면에서 올리면 **인스타그램 캐러셀 게시물**로 올려주는
1인용 로컬 도구입니다. 캡션은 직접 쓰거나, 올린 카드를 AI 가 읽고 초안을 써줍니다.

```
카드 업로드 → 드래그로 순서 조정 → 캡션 작성 → 미리보기 → 테스트 → 발행
```

내 PC 에서만 돕니다. 계정 정보와 API 키는 내 컴퓨터의 `config.json` 에만 저장되고
어디로도 전송되지 않습니다.

## 필요한 것

- **Python 3.10 이상**
- **Google Chrome** (설치만 되어 있으면 됩니다)
- 인스타그램 계정
- (선택) **Anthropic API 키** — AI 캡션 초안에만 씁니다. 없어도 발행은 됩니다.
  [console.anthropic.com](https://console.anthropic.com) 에서 발급합니다.

## 설치

```bash
git clone <이 저장소 주소>
cd insta-manual
python3 -m venv .venv
./.venv/bin/python -m pip install -r requirements.txt
```

## 실행

```bash
./run.sh
```

브라우저에서 **http://127.0.0.1:5252** 를 엽니다.
`127.0.0.1` 에 고정되어 있어 같은 와이파이의 다른 기기에서도 접근할 수 없습니다.

## 처음 한 번

1. 화면이 열리면 **설정** 창이 자동으로 뜹니다. **인스타그램 아이디**(@ 없이)를 넣고 저장합니다.
   AI 초안을 쓰려면 Anthropic API 키도 같이 넣습니다.
2. **`인스타 로그인`** 버튼을 누릅니다. Chrome 창이 열리면 **그 창에서 직접 로그인**하세요.
   로그인이 끝나면 자동으로 감지하고 창이 닫힙니다. 세션은 `chrome-profile/` 에 저장되어
   다음부터는 다시 로그인하지 않아도 됩니다.

> 아이디·비밀번호와 보안확인(CAPTCHA)은 **반드시 사람이 직접** 입력합니다.
> 이 앱은 자격증명을 저장하거나 대신 입력하지 않습니다.

## 쓰는 법

**1 · 카드 이미지** — 드래그&드롭 또는 클릭해서 선택합니다(최대 10장, PNG/JPG).
올린 뒤 썸네일을 **드래그해서 순서를 바꿀 수 있고**, `×` 로 뺍니다.

캐러셀은 **첫 장의 비율에 맞춰 나머지가 잘립니다.** 비율이 섞여 있거나 첫 장이 1:1 이
아니면 경고가 뜹니다. 카드뉴스는 1:1 또는 4:5 를 권합니다.

**2 · 캡션** — 직접 쓰거나 `✨ AI 초안` 을 누릅니다. AI 는 **올린 카드 이미지를 직접 읽고**
거기 담긴 내용만으로 캡션을 씁니다(없는 사실을 지어내지 않도록 지시되어 있습니다).
옆 메모칸에 방향을 적으면 반영합니다. 초안일 뿐이니 그대로 고쳐 쓰면 됩니다.

`첫 댓글로 분리` 를 켜면 본문은 깔끔해지고 해시태그가 첫 댓글로 갑니다.

**3 · 미리보기** — 실제 게시에 쓰이는 것과 **같은 코드로** 최종 문구를 조립해 보여줍니다.

**4 · 발행**

| 버튼 | 동작 |
|---|---|
| `인스타 로그인` | Chrome 을 열어 직접 로그인 (세션 저장) |
| `로그인 확인` | 게시하지 않고 세션만 점검 |
| `테스트` | 캡션 입력까지 전부 하고 **'공유하기' 직전에 멈춤** — 게시되지 않음 |
| `인스타에 발행하기` | 확인창을 거친 뒤 실제 게시 |

작업 중에는 Chrome 창이 열립니다. **창을 닫지 마세요.** 여러 장 업로드는 공유에
시간이 걸리는데, 그때 창을 닫으면 게시가 중단됩니다.

보안확인(CAPTCHA)이 뜨면 그 창에서 직접 풀어 주세요. 최대 3분 기다렸다가 이어서 진행합니다.

## 잘 안 될 때

버튼을 못 찾는 오류가 나면 **`logs/` 폴더의 스크린샷**을 먼저 보세요. 단계마다 저장됩니다.

| 스크린샷 | 뜻 |
|---|---|
| `not_logged_in` | 로그인 세션 만료 → `인스타 로그인` 다시 |
| `challenge` | 보안확인/CAPTCHA → Chrome 창에서 직접 해결 |
| `no_create_button`, `no_file_input`, `stuck` | 인스타 DOM 변경 |
| `caption_screen`, `before_share` | 정상 진행 중(테스트 결과 확인용) |

인스타그램은 화면 구조와 버튼 문구를 자주 바꿉니다. 그 경우 스크린샷을 보고
[`instagram.py`](instagram.py) 위쪽의 라벨 목록(`CREATE_LABELS`, `NEXT_LABELS`,
`SHARE_LABELS` 등)에 새 문구를 추가하면 대개 해결됩니다.

## 설정 항목

전부 화면의 **설정** 창에서 바꿉니다. `config.json` 을 직접 편집해도 됩니다.

| 항목 | 설명 |
|---|---|
| 인스타그램 아이디 | 필수. 첫 댓글을 달 때 내 프로필을 찾는 데 씁니다 |
| Anthropic API 키 | 선택. AI 초안에만 사용. 저장 후에는 화면에 다시 표시되지 않습니다 |
| 캡션 모델 | 기본 Claude Opus 5. 더 저렴한 모델도 고를 수 있습니다 |
| 계정 소개 | 선택. AI 가 톤을 맞추는 데 참고합니다 |
| 캡션 끝 문구 | 선택. 모든 캡션 끝에 자동으로 붙습니다 |
| 기본 해시태그 | 화면에 미리 채워질 태그 |
| 항상 포함할 태그 | 개수 제한에 관계없이 **항상** 들어가는 태그(브랜딩용) |
| AI 레이블 | AI 로 만든 이미지라면 켜세요 |

## 구조

| 파일 | 역할 |
|---|---|
| `app.py` | 웹 서버(업로드·캡션·미리보기·발행·설정). 한 번에 한 작업만 실행 |
| `instagram.py` | 인스타 게시 전부(Selenium). 이 파일만으로 완결됩니다 |
| `caption_ai.py` | 카드 이미지를 Claude 에게 보여주고 캡션 초안 받기 |
| `core.py` | 설정 저장·경로·로그 |
| `templates/index.html` | 화면 전부 |

## 알아두실 점

- **인스타그램 웹 자동화는 Meta 이용약관이 권장하는 방식이 아닙니다.** 이 도구는 사람이
  직접 로그인한 실제 브라우저 프로필로, 누를 때만 1건씩 동작해 위험을 낮췄지만
  계정 제재 가능성이 0 은 아닙니다. 본인 판단으로 사용하세요.
- **자동 스케줄 실행에는 적합하지 않습니다.** 특히 GitHub Actions 같은 클라우드에서는
  데이터센터 IP 가 차단되고 CAPTCHA 를 풀 사람이 없어 사실상 동작하지 않습니다.
  자동화가 필요하면 **Instagram Graph API**(공식) 를 쓰세요. 프로페셔널 계정,
  페이스북 페이지 연결, Meta 앱 등록, 이미지의 공개 HTTPS URL 이 필요합니다.
- **비용**: AI 초안 1회에 몇 센트. 안 쓰면 0 원.
